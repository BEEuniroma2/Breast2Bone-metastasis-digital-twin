# Breast2Bone-metastasis-digital-twin
This repository contains the code and data associated with the paper:

"An AI-Driven Closed-Loop Organ-on-Chip Platform for Quantitative Cell Behavior Modeling: a Breast-to-Bone Metastasis Case Study"

The code was developed in MATLAB® R2024b.

The repository is organized into four subfolders:

- motility
- morphodynamics
- interaction
- ABM

Each folder contains the data and code required to reproduce the results presented in the paper.
